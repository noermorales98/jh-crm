# PRODUCT — JH Financial CRM

## Objetivo

Centralizar la captación, conversión y administración de clientes de JH Financial, permitiendo administrar uno o varios servicios por persona y mantener trazabilidad de tareas, documentos, pagos, comunicaciones y avances específicos de cada servicio.

## Usuario principal

Hugo.

El sistema debe priorizar velocidad operativa y claridad sobre dashboards decorativos.

Al entrar al CRM, el usuario debe poder responder rápidamente:

1. ¿Qué tengo que hacer hoy?
2. ¿Qué está atrasado?
3. ¿Qué clientes están esperando seguimiento?

## Tipo de producto

No es solamente un CRM de contactos.

Es una combinación de:

- CRM de ventas.
- Gestión de expedientes.
- Seguimiento de servicios.
- Tareas.
- Documentos.
- Notas.
- Pagos.
- Seguimiento de reparación de crédito.
- Testimonios.

## Servicio principal

`CREDIT_REPAIR`

Este módulo recibe la mayor prioridad del MVP.

## Otros servicios contemplados

- `HOME_BUYER`
- `BUSINESS_CREDIT`
- `PERSONAL_LOAN`
- `WEB_DEVELOPMENT`
- `CRM_DEVELOPMENT`

## Fuera del alcance actual

- LLC / creación de compañías.
- Integración automática con burós.
- Procesamiento automático de tarjetas.
- Contabilidad completa.
- Comisiones/afiliados.
- WhatsApp/SMS automáticos.
- Editor visual de pipelines.

## Principio central

Una persona no tiene un único servicio ni un único estado.

Una persona puede tener múltiples `ServiceCase`, cada uno con:

- estado;
- etapa;
- tareas;
- documentos;
- notas;
- pagos;
- fechas;
- historial.
